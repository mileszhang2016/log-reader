# LR04 MySQL 启动连接失败后台重试场景（scenario-LR04-mysql-startup-connect-retry）

## 场景概述

验证 `mod_log_mysql` 的启动连接容错：MySQL（`bfe_report`）不可达时 log-reader **不退出**，后台持续重试；断连期间日志入队缓冲；MySQL 恢复后自动建连并排空积压。同时守护 fail-fast 分界——配置错误（如 `Mysql.Addr` 为空）仍立即退出。

修改设计见 `doc/modifications/2026-09-29-mod-log-mysql-startup-connect-retry/design-changes.md`。

## 被测进程与配置

- **被测进程**：真实 `log-reader` 二进制，`Modules = mod_log_mysql`，`-b` 从文件头读取；monitor 端口由测试预先占用（`common.FreePort`）并经 `{{HTTP_PORT}}` 注入 `config.conf`（`StartLogReaderOnPort`），供测试轮询 `/monitor/mod_log_mysql`。
- **MySQL 不可达模拟**：testcontainers 启动 `mysql:8.0` → 建库 → 应用 DDL → `common.MysqlEnv.Pause`（Docker `ContainerPause` 冻结容器进程；新连接 TCP 挂起）。恢复用 `Unpause`。外部 `LR_MYSQL_DSN` 后端无法 Pause/Unpause，TC-04-01 调用即 `t.Skip`。
- **建连配置**（`testdata/mod_log_mysql/mod_log_mysql.conf`）：`ConnectTimeoutMs = 2000`、`ConnectRetryIntervalMs = 200`，使重试循环在测试时间内可观测。
- **harness 扩展**：`ProcessEnv.StartLogReaderEx/OnPort`（进程退出探测 `waitExit`）、`common.FetchMonitor/WaitMonitor`（monitor JSON 抓取，`MYSQL_CONN_STATE` 等键值只能经 HTTP 观测）。

## 测试用例

| 用例 | 文件 | 说明 |
|------|------|------|
| TC-04-01 启动不可达：存活→重试→恢复补写 | `lr04_mysql_startup_retry_test.go` `TestLR04_StartupMysqlDownThenRecover` | Pause MySQL 后启动 log-reader：① `waitExit(3s)` 未退出且 `/monitor/mod_log_mysql` 可访问；② `MYSQL_CONN_STATE=DOWN` 且 `MYSQL_CONN_RETRY` 持续增长；③ 写 3 条日志后 `SENT_TO_MYSQL=3` 而 `WRITE_BATCH_SIZE=0`（缓冲未写出）；④ Unpause 后 `STATE=UP`（60s 内）、`MYSQL_CONN_OK=1`、`MYSQL_CONN_RETRY>=1`；⑤ 表行数=3 且 logid 齐全（积压排空、幂等落库） |

## 关键断言点

- **进程存活**是本改动核心：`waitExit` 在 MySQL 不可达时必须返回 `exited=false`（改动前行为为 `Exit(1)`）。
- **观测通道**：`MYSQL_CONN_STATE`/`MYSQL_CONN_RETRY`/`MYSQL_CONN_OK`/`SENT_TO_MYSQL`/`WRITE_BATCH_SIZE` 经 `/monitor/mod_log_mysql`（默认 JSON：`States`/`SCounters` 两个 map）。
- **恢复闭环**：Pause 状态新连接 TCP 挂起而非拒绝，TC-04-01 同时覆盖 `PingContext` 超时路径（`ConnectTimeoutMs` 生效）。
- **断连期背压语义**：`SENT_TO_MYSQL`（入队）增长、`WRITE_BATCH_SIZE`（实际写库）为 0。

## 环境要求与运行方式

```bash
# 需 Docker（testcontainers Pause/Unpause）；仅 LR_MYSQL_DSN 时 TC-04-01 skip、TC-04-02 仍执行
go test ./tests/integration/implementation/scenario-LR04-mysql-startup-connect-retry/ -v

# 单用例
go test ./tests/integration/implementation/scenario-LR04-mysql-startup-connect-retry/ \
  -run TestLR04_ConfigErrorStillFailFast -v
```

## 不在本场景范围

- **运行期断连**（已建连后 MySQL 挂掉）：维持原语义（写失败退避重试后丢弃计 `SEND_MYSQL_FAILED`，进程不退出；网络恢复后 `database/sql` 连接池自行换连接恢复写入）。Pause 下连接池拨号无超时（DSN 未配 `timeout`），断言窗口不稳定，一期手工验证（design-changes.md 验证步骤 2.4），自动化列二期。
