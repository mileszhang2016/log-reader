# TC-03 零值规则

## 用例编号与名称

TC-03 零值规则（`TestLR03_ZeroValueToNull`）

## 所属场景

LR03 MySQL 写入场景（scenario-LR03-mysql-write）

## 版本声明

- `log-reader`：当前源码版本（含 `mod_log_mysql` 模块）

## 测试目的

验证写入侧的零值规则：字符串零值（""）映射为 NULL；空结构化字段（空 header 列表、空字符串数组、未设置的标签层级）映射为 NULL；布尔/数值零值按原样写 0（而非 NULL）。同时验证未认证请求（`ai_apikey_id` 为空→NULL）可以正常写入（幂等键字符串列允许 NULL）。

## 运行模式

单组件模式：真实 `log-reader` 进程 + 真实 MySQL。

## 前置条件

同 TC-01。

## 配置构造

同 TC-01。

## 输入数据

一条手工构造的最小请求日志：proto2 必填字段（`product`、`timestamp`、`logid`、`log_type`、`err_code`、`err_msg`、`addr_info`、`client_ip`、`req_num`、`proto`、`header_host`、`origin_uri`、`method`、`all_time`）全部置语义零值（空串/0/false），仅设置 `ai_requested_model = zero-model`，不设置任何 AI 字段、header 列表与标签。

## 操作步骤

1. 准备环境并启动 `log-reader`。
2. 写入该日志，轮询等待表行数 ≥ 1（超时 20s）。
3. 按 `logid = 81001` 查询该行并逐列断言。

## 预期结果

- 字符串零值列为 NULL：`err_code`、`err_msg`、`proto`、`header_host`、`origin_uri`。
- 空结构列为 NULL：`req_headers`、`ai_auth_hit_quota_plans`、`level1`（未设置标签层级）。
- 布尔/数值零值写 0 而非 NULL：`is_trust_src_ip = 0`、`ai_stream = 0`、`ai_input_tokens = 0`。
- `ai_requested_model = zero-model` 正常落库；整批写入无 Error 1048（幂等键字符串列可空）。

## 清理

停止 `log-reader` 进程，关闭数据库连接，DROP 测试专用数据库，删除临时目录。
